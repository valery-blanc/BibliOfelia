# Carte de membre

Chaque membre dispose d'une carte physique avec un code-barres. C'est
elle qui permet de l'identifier rapidement lors d'un prêt.

## Imprimer une carte unique

Depuis la [fiche du membre](fiche.md), cliquez sur **Imprimer la carte**
(ou allez dans **Avancé → Impressions → Cartes**).

## Imprimer plusieurs cartes en une fois

Pour les nouvelles inscriptions, il est plus efficace de regrouper :

1. Ouvrez **Avancé → Impressions → Cartes**
2. Filtrez les membres à imprimer (par exemple, "inscrits ce mois-ci")
3. Cochez les cartes voulues
4. Cliquez sur **Générer le PDF**

![Page de génération des cartes](../assets/screenshots/fr/impressions/cards-picker.png)

Le PDF s'ouvre dans un nouvel onglet : vous pouvez l'imprimer
directement ou le sauvegarder pour plus tard.

## Format de la carte

Les cartes BibliOfelia sont au format standard de carte de visite
(85 × 54 mm) avec :

- Le **logo OFELIA** en filigrane
- La **photo du membre** (en haut à gauche, si fournie)
- Le **nom et prénom** en grand
- Le **numéro de carte** et le **code-barres EAN-13**
- La **date d'expiration**
- Un **drapeau** indiquant la langue préférée du membre

Le fond est crème pour cohérence avec la charte OFELIA.

!!! tip "Quel papier utiliser ?"
    Pour une carte solide, imprimez sur papier 200-300 g/m² puis
    plastifiez. Vous pouvez aussi imprimer sur étiquettes adhésives à
    coller sur des cartes pré-imprimées vierges.

## Remplacer une carte

Si un membre perd sa carte, vous devez attribuer un **nouveau numéro**
(et pas réimprimer l'ancien) pour invalider la carte perdue :

1. Ouvrez la fiche du membre
2. Cliquez sur **Remplacer la carte**
3. Confirmez

Un nouveau numéro est attribué et l'ancien est "tombé" : il ne sera
jamais réattribué à un autre membre (voir [Cas courants : carte
perdue](../cas-courants/carte-perdue.md)).

Imprimez ensuite la nouvelle carte normalement.
