# Récolement (inventaire des rayons)

Le **récolement** est l'opération qui consiste à passer dans les rayons
et vérifier que chaque livre est à sa place. Avec OfeliaScan, c'est
l'opération la plus puissante du système — vous parcourez les étagères
en scannant, et BibliOfelia se met à jour automatiquement.

## Préparer le récolement

Avant de commencer :

1. Choisissez la **localisation** à récoler (un seul rayon à la fois
   pour ne pas se perdre)
2. Munissez-vous de votre téléphone avec OfeliaScan
3. Ouvrez la page **Avancé → Inventaire** sur l'ordinateur

## Démarrer une session de récolement

Sur l'ordinateur :

1. Cliquez sur **Nouvelle session de récolement**
2. Choisissez la **portée** : une localisation précise (ex. "Rayon A1")
   ou tout le catalogue
3. Validez

Sur le téléphone, OfeliaScan reçoit la session. Vous voyez la portée
choisie et un compteur à 0.

## Scanner les livres

Dans le rayon, scannez chaque livre l'un après l'autre. Pour chaque
scan :

- Si le livre est **dans la bonne localisation** : il est marqué
  "vu", rien ne change
- Si le livre est **dans une autre localisation** : BibliOfelia met
  automatiquement à jour sa localisation vers le rayon courant
- Si le code n'existe pas : OfeliaScan vous prévient (étiquette
  inconnue, à investiguer)

!!! tip "Allez vite, ne réfléchissez pas"
    Inutile de vérifier chaque scan manuellement : BibliOfelia trie
    tout à la fin. Concentrez-vous sur la vitesse et la couverture
    complète du rayon.

## Clôturer la session

Une fois le rayon parcouru :

1. Sur le téléphone, appuyez sur **Terminer la session**
2. Sur l'ordinateur, ouvrez le rapport de récolement

Vous voyez :

- Nombre de livres scannés
- Nombre de livres **manquants** (présents dans la base, pas vus dans
  le rayon)
- Nombre de livres **déplacés** automatiquement
- Nombre de **codes inconnus** rencontrés

## Que faire des livres manquants ?

Pour chaque livre signalé manquant, deux possibilités :

- **Il est ailleurs dans la bibliothèque** : faites un récolement sur
  les autres rayons, il sera automatiquement repositionné
- **Il est perdu** : marquez l'exemplaire comme **Perdu** depuis sa
  fiche (voir [Livre perdu](../cas-courants/livre-perdu.md))

## Fréquence recommandée

- **Petite bibliothèque** : récolement complet 1 à 2 fois par an
- **Grande bibliothèque** : 1 rayon par mois en rotation

Faites-le idéalement quand la bibliothèque est calme (matin, jour de
fermeture).
