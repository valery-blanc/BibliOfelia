# Prêt et retour avec OfeliaScan

OfeliaScan ne fait pas les prêts et retours tout seul : il sert
uniquement à **scanner** les codes-barres. C'est BibliOfelia sur
l'ordinateur qui enregistre l'opération.

Le principe : votre téléphone est une "douchette sans fil".

## Workflow type pour un prêt

1. Sur l'ordinateur, ouvrez la page **Prêt**
2. Cliquez sur **Scanner la carte** dans la section Membre
3. OfeliaScan s'ouvre sur votre téléphone (vibreur ou son)
4. Pointez la caméra sur la carte du membre
5. Dès que le code est lu, le téléphone vibre — BibliOfelia identifie
   le membre automatiquement
6. Cliquez sur **Scanner un livre** dans la section Livres
7. Scannez chaque livre l'un après l'autre
8. Cliquez sur **Prêter N livres** pour confirmer

## Workflow type pour un retour

Encore plus simple :

1. Ouvrez la page **Retour**
2. Cliquez sur **Scanner un livre**
3. Scannez tous les livres rendus, l'un après l'autre
4. Chaque scan enregistre automatiquement le retour

## Quand préférer OfeliaScan à la douchette ?

- **Le poste est éloigné de l'étagère** où sont les livres
- **Plusieurs étagères** à parcourir en marchant
- **Caisse de livres** au sol, accroupi, douchette pas pratique
- **Plus d'une personne** sert en parallèle (plusieurs téléphones,
  un poste central)

## Quand la douchette reste meilleure

- **Réception immédiate** (membres qui défilent à l'accueil) : la
  douchette filaire est plus rapide
- **Codes-barres abîmés** : OfeliaScan peut galérer sur des étiquettes
  pliées ou rayées que la douchette laser lit sans souci

## Problèmes courants

### OfeliaScan ne s'ouvre pas

Vérifiez que :

- Le téléphone est appairé à la Box (voir [Activer
  OfeliaScan](activer.md))
- Le téléphone et la Box sont sur le même réseau Wi-Fi
- L'application n'est pas mise en veille profonde par Android (sortez
  d'OfeliaScan de la mise en veille batterie dans les paramètres
  Android)

### Le scan ne déclenche rien

Le code-barres est peut-être mal lu : essayez d'éloigner ou rapprocher
le téléphone, vérifiez l'éclairage. Vous pouvez aussi taper le code
au clavier directement sur l'ordinateur.
