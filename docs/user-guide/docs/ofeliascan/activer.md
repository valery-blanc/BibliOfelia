# Activer OfeliaScan

**OfeliaScan** est l'application Android compagnon de BibliOfelia. Une
fois installée et appairée à votre Ofelia Box, elle vous permet de
scanner les codes-barres depuis le téléphone et d'envoyer le résultat
directement à BibliOfelia sur l'ordinateur.

!!! info "La caméra est désormais intégrée au site"
    Vous n'avez plus besoin d'OfeliaScan pour les scans courants : les
    boutons **Scanner** du site ouvrent directement la **caméra du
    navigateur** (voir [Scanner avec la
    caméra](../premiers-pas/scanner-camera.md)). OfeliaScan reste utile
    comme **complément mobile**, notamment pour envoyer de **gros lots** de
    catalogage ou de récolement.

## Quand l'utiliser ?

- **Récolement** : faire l'inventaire dans les rayons sans pousser un
  poste avec douchette
- **Catalogage** : enregistrer des livres en série depuis une caisse
  d'arrivée
- **Quand votre douchette est cassée** : OfeliaScan dépanne avec un
  smartphone

## Installer OfeliaScan

L'application s'installe depuis :

- Le **Play Store** Android (recherchez "OfeliaScan")
- Ou par **téléchargement direct** depuis votre Ofelia Box si vous
  n'avez pas le Play Store

Demandez à l'administrateur de la Box pour la procédure exacte
d'installation.

## Appairer le téléphone

Une fois OfeliaScan installé, il faut le connecter à votre Box (à
faire **une seule fois**).

1. Sur l'ordinateur, ouvrez BibliOfelia et allez dans **Avancé → Accès
   OfeliaScan**
2. Un QR code s'affiche à l'écran
3. Sur le téléphone, ouvrez OfeliaScan et appuyez sur **Appairer**
4. Pointez la caméra sur le QR code
5. L'appairage est confirmé sur les deux écrans

Le téléphone est maintenant lié à votre Box. Il s'en souviendra à
chaque utilisation.

!!! info "Plusieurs téléphones, une Box"
    Plusieurs bibliothécaires peuvent appairer leur téléphone à la
    même Box. Chacun voit ses propres scans dans BibliOfelia.
