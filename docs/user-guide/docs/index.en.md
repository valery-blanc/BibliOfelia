# Welcome to BibliOfelia

User guide for librarians.

## Who this guide is for

This guide accompanies librarians using BibliOfelia day to day:
registering loans, enrolling members, managing the catalog, printing
cards and labels.

## Where to start

- First steps: **[Sign in](premiers-pas/connexion.md)** then
  **[Dashboard tour](premiers-pas/dashboard.md)**.
- The most frequent action: **[Lending a book](prets-retours/faire-pret.md)**.
- Enrolling a new member: **[Enrollment](usagers/inscription.md)**.

## Contents

1. **Getting started** — sign in, dashboard, input methods
2. **Catalog** — books, copies, search, bulk operations
3. **Members** — enrollment, profile, member card
4. **Loans and returns** — daily routine
5. **Reservations** — queue, notifications, pickup
6. **OfeliaScan mobile** — Android scanner
7. **Printing** — member cards + book labels
8. **Reports** — KPIs and CSV exports
9. **Common cases** — lost book, lost card, overdue
10. **FAQ and glossary**
