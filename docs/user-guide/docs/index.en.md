# Welcome to BibliOfelia

User guide for librarians.

## Who this guide is for

This guide accompanies librarians using BibliOfelia day to day:
registering loans, enrolling members, managing the catalog and the
cash desk, printing cards and labels.

## Where to start

- First steps: **[Sign in](premiers-pas/connexion.md)** then
  **[Dashboard tour](premiers-pas/dashboard.md)**.
- The most frequent action: **[Lending a book](prets-retours/faire-pret.md)**.
- Enrolling a new member: **[Enrollment](usagers/inscription.md)**.

## Contents

1. **Getting started** — home, sign in, dashboard, input methods, camera scan
2. **Catalog** — books, copies, search, bulk operations, inventory
3. **Members** — enrollment, profile, member card
4. **Cash desk** — invoices, fees, activities, end-of-day closing
5. **Loans** — loans, returns, renewals, on-site, reservations
6. **Printing** — member cards + book labels
7. **Reports** — KPIs and CSV exports
8. **FAQ** — frequent questions and difficult cases (lost book, lost card, overdue)
9. **Glossary**
