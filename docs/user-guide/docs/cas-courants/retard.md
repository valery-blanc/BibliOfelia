# Retard prolongé

Quand un membre dépasse largement la date de retour d'un livre, vous
avez plusieurs leviers selon la gravité de la situation.

## Suivre les retards

Le tableau de bord affiche en permanence le compteur **Prêts en
retard** et la section **Relances à faire** en bas, qui liste les
prêts les plus en retard.

Pour une vue complète, ouvrez **Rapports → Prêts en retard**.

## Premier niveau : appeler le membre

Pour les retards d'une semaine ou deux :

1. Ouvrez la fiche du membre depuis la liste des retards
2. Notez son téléphone (visible dans la section Coordonnées)
3. Appelez-le pour lui rappeler le retour

Idéalement, faites un tour d'appels toutes les semaines.

## Deuxième niveau : blocage des prêts

Tant qu'un membre a un prêt en retard, BibliOfelia continue à lui
permettre d'emprunter (sauf si vous changez les paramètres). Si vous
voulez bloquer les nouveaux prêts pour les retards :

- Solution simple : **désactivez** temporairement le membre depuis sa
  fiche. Réactivez-le quand il rapporte les livres.
- Solution conventionnelle : convenez d'une règle informelle ("pas de
  prêt si retard") et appliquez-la manuellement à l'accueil.

## Troisième niveau : marquer le livre perdu

Pour les retards très longs (plusieurs mois) où vous estimez le livre
définitivement perdu :

1. Ouvrez la fiche du membre
2. Trouvez le prêt concerné
3. Cliquez sur **Perdu**

Voir [Livre perdu ou abîmé](livre-perdu.md) pour les conséquences.

## Réinscription d'un ancien membre

Si un membre revient à la bibliothèque après une longue absence avec
un livre en retard depuis des années :

- Acceptez le retour normalement (pas de blocage au retour)
- Renouvelez sa carte si elle est expirée
- Discutez du livre perdu (vous pouvez décider de l'absoudre)

## Communication avec les membres

BibliOfelia ne génère pas automatiquement de lettre de relance.
Quelques options selon vos moyens :

- **Téléphone** : le plus efficace pour une petite bibliothèque
- **SMS** depuis votre propre téléphone (BibliOfelia ne le fait pas)
- **Affichage** : liste des retards sur un tableau à l'entrée
- **Bouche-à-oreille** : dans les petites communautés, ça marche
