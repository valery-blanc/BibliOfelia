# Dashboard KPIs

The dashboard permanently displays six **KPIs** (key indicators)
that summarize the state of the library.

![Dashboard counters](../assets/screenshots/en/premiers-pas/dashboard.png)

## The six counters

### Active loans

Number of books currently borrowed. Includes current and overdue
loans, but not finished ones.

### Overdue loans

Subset of active loans whose return date has passed. Click it to see
the [detailed list](/bibliofelia/en/reports/overdue/){ target="_blank" } and
call the members.

### Ready reservations

Reservations whose book is available (already returned, set aside).
These are notifications to do.

### Members enrolled

Total of active cards. Does not include deactivated members or
expired cards.

### Records

Total number of records (book entries) in the catalog.

### Copies

Total number of physical copies in the library. Always greater than
or equal to the number of records (a record can have multiple
copies).

## Tracking activity

The **Activity** section complements the counters with figures over
30 days and 1 year:

- Active members (having borrowed at least once)
- Records and copies added
- Monthly and yearly loans

## System status

For librarians, **System status** helps spot when something is wrong:

- **Disk space**: if too low, warn the administrator
- **Last backup**: must be today or yesterday
- **Network**: must be "online" except during outages
