# Bienvenido a BibliOfelia

Guía de usuario para bibliotecarios.

## A quién va dirigida esta guía

Esta guía acompaña a los bibliotecarios que usan BibliOfelia a
diario: registrar préstamos, inscribir miembros, gestionar el
catálogo, imprimir tarjetas y etiquetas.

## Por dónde empezar

- Primeros pasos: **[Iniciar sesión](premiers-pas/connexion.md)**
  luego **[Recorrido del panel](premiers-pas/dashboard.md)**.
- La acción más frecuente: **[Hacer un préstamo](prets-retours/faire-pret.md)**.
- Inscribir un nuevo miembro: **[Inscripción](usagers/inscription.md)**.

## Índice

1. **Primeros pasos** — iniciar sesión, panel, modos de entrada
2. **Catálogo** — libros, ejemplares, búsqueda, operaciones en lote
3. **Miembros** — inscripción, ficha, tarjeta de miembro
4. **Préstamos y devoluciones** — la rutina diaria
5. **Reservas** — cola, notificaciones, recogida
6. **OfeliaScan móvil** — escáner Android
7. **Impresión** — tarjetas de miembros + etiquetas de libros
8. **Informes** — KPIs y exportaciones CSV
9. **Casos frecuentes** — libro perdido, tarjeta perdida, atraso
10. **FAQ y glosario**

!!! tip "Esta guía está disponible en 4 idiomas"
    Use el selector en la parte superior derecha para cambiar entre
    Français, English, Español o Malagasy.
