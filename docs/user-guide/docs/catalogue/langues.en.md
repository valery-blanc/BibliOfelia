# Languages

BibliOfelia keeps **a single list of languages**, used for two things:

- the **language of a book**, on the record;
- the **spoken languages** of a member, on their profile.

You can edit it: open [**Advanced**](/bibliofelia/en/advanced/){ target="_blank" }
then **Languages**.

## Adding a language

Click **New language**, then fill in:

- **Code** — the international abbreviation: `fr`, `en`, `pt`, `de`…
- **Name** — the name of the language

Add one as soon as a book or a reader needs it: the list shipped with
BibliOfelia covers 22 languages, but a collection can hold any of them.

!!! tip "No regional variants"
    Use the main code, without splitting by country: **`fr`** covers French from
    France, Canada and Switzerland; **`pt`** covers Portuguese and Brazilian.
    Multiplying regional codes would shatter your filters for nothing.

## The order of the menus

Drop-down lists are sorted **alphabetically**, in the interface language. In
French "Albanais" comes first, in English it is "Albanian": the order therefore
changes from one language to another, and that is on purpose.

## Removing a language

Removing a language from the list **does not touch any book**. The records
concerned keep their code, which will show as-is (for example `de`) instead of
the translated name. The language is simply no longer offered when typing.
