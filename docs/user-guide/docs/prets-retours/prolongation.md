# Prolonger un prêt

Si un membre veut garder un livre plus longtemps, vous pouvez prolonger
son prêt sans qu'il ait besoin de rapporter le livre.

## Depuis la fiche du membre

Le moyen le plus simple : ouvrez la [fiche du membre](../usagers/fiche.md)
et trouvez le prêt à prolonger dans la section **Prêts en cours**.

![Prêts en cours sur la fiche d'un membre](../assets/screenshots/fr/usagers/member-detail.png)

À droite de chaque ligne, le bouton **Renouveler** prolonge la date de
retour d'une durée standard (par défaut 21 jours à compter
d'aujourd'hui).

## Combien de fois peut-on prolonger ?

Par défaut, un prêt peut être renouvelé une fois. Au-delà,
BibliOfelia bloque le renouvellement : le membre doit ramener le livre
(quitte à le réemprunter ensuite si personne ne l'a réservé).

Ce maximum est configurable par l'administrateur dans les paramètres.

## Cas où le renouvellement est refusé

- **Le livre est réservé** par un autre membre : pas de renouvellement
  possible, le membre actuel doit rendre le livre
- **Le membre a atteint le nombre maximum de renouvellements** pour ce
  prêt
- **La carte du membre est expirée** : renouvelez la carte d'abord
  ([Renouvellement de carte](../usagers/renouvellement.md))

## Cas particulier : prolongation sans avoir le livre sous les yeux

Si le membre vous appelle au téléphone pour demander une prolongation,
ouvrez sa fiche depuis la recherche globale (tapez son nom), trouvez
le livre concerné et cliquez sur **Renouveler**. Aucun scan nécessaire.
