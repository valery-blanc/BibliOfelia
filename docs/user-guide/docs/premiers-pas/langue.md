# Changer de langue

BibliOfelia est disponible en quatre langues : **Français**, **English**,
**Español** et **Malagasy**. Chaque bibliothécaire peut choisir sa langue
indépendamment des autres.

## Le sélecteur de langue

Dans la barre du haut, à droite, vous voyez une petite pastille avec le
code de votre langue actuelle (par exemple **FR**) et un globe terrestre.

Cliquez dessus pour ouvrir le menu déroulant, puis sélectionnez la
langue souhaitée. La page recharge immédiatement dans la nouvelle langue.

## Ce qui change avec la langue

- L'interface (menus, boutons, messages) bascule entièrement
- Les catégories standard (Adulte, Enfant, Roman, Documentaire…) sont
  traduites
- Les noms de membres, les titres de livres, les notes restent dans la
  langue d'origine (ce sont vos données)

!!! info "Préférence enregistrée"
    Votre choix de langue est mémorisé sur votre poste : la prochaine
    fois que vous ouvrez BibliOfelia, l'interface se présente dans la
    même langue.

## Bibliothèque multilingue

Si votre bibliothèque accueille des lecteurs de plusieurs langues,
vous pouvez :

- Catégoriser les livres par langue dans le **Catalogue**
- Saisir des titres dans n'importe quelle langue (l'interface s'adapte
  aux caractères accentués et alphabets non-latins)
- Imprimer les cartes de membres et étiquettes dans la langue choisie
  au moment de l'impression
