# Modos de entrada: escáner, OfeliaScan o teclado

BibliOfelia está diseñado para funcionar con o sin equipo específico.
Elija el modo que corresponda a su equipo.

## El escáner (recomendado para el uso diario)

Un escáner USB conectado a su puesto se comporta como un teclado:
escribe el contenido del código de barras y pulsa **Enter**
automáticamente. Es el modo más rápido y menos cansado.

**Ventajas:**

- Acción instantánea (menos de 1 segundo por escaneo)
- Sin fatiga para las manos
- Funciona en cualquier página con un campo de entrada

**Limitación:** el escáner debe estar conectado al puesto donde
trabaja.

## OfeliaScan (teléfono móvil)

OfeliaScan es la aplicación Android compañera de BibliOfelia. Escanea
con la cámara del teléfono y el resultado se envía a BibliOfelia.

**Ventajas:**

- No necesita escáner ni puesto al lado de cada estantería
- Ideal para inventario (caminar entre los estantes)

**Limitaciones:**

- Primera vez: hay que [emparejar el teléfono](../ofeliascan/activer.md)
- Más lento que un escáner (la cámara debe leer el código)

## El teclado (siempre disponible)

En cada página con un campo de entrada, puede escribir el código
manualmente y pulsar **Enter** o hacer clic en **Validar** al lado.

**Cuándo usarlo:**

- Sin escáner conectado
- El código de barras está dañado o mal impreso
- Debe escribir un código que anotó a mano

!!! tip "Consejo"
    En las páginas **Préstamo** y **Devolución**, el cursor se sitúa
    automáticamente en el campo correcto después de cada escaneo o
    validación. Nunca necesita hacer clic para pasar al siguiente
    libro.

## Búsqueda por nombre en lugar del código de barras

Si no tiene la tarjeta del miembro ni el libro a la mano, use la
**búsqueda global** en la parte superior de cada página: escriba el
nombre del miembro o una palabra del título, y BibliOfelia encuentra
la ficha directamente.
