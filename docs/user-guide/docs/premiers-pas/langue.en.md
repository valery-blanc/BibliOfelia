# Change language

BibliOfelia is available in four languages: **Français**, **English**,
**Español** and **Malagasy**. Each librarian can choose their own
language independently.

## The language selector

In the top bar, on the right, you see a small pill with your current
language code (for example **EN**) and a globe.

Click on it to open the dropdown menu, then pick the language you
want. The page immediately reloads in the new language.

## What changes with the language

- The interface (menus, buttons, messages) switches entirely
- Standard categories (Adult, Child, Novel, Documentary…) are translated
- Member names, book titles, notes stay in their original language
  (these are your data)

!!! info "Preference remembered"
    Your language choice is stored on your workstation: next time you
    open BibliOfelia, the interface appears in the same language.

## Multilingual library

If your library serves readers in several languages, you can:

- Categorize books by language in the **Catalog**
- Type titles in any language (the interface supports accented
  characters and non-Latin scripts)
- Print member cards and book labels in any of the four languages —
  the language is chosen at print time
