# Modes de saisie : douchette, OfeliaScan ou clavier ?

BibliOfelia est conçu pour fonctionner avec ou sans matériel spécifique.
Choisissez le mode qui correspond à votre équipement.

## La douchette (recommandé pour le quotidien)

Une douchette USB branchée sur votre poste se comporte comme un clavier :
elle tape le contenu du code-barres puis envoie **Entrée**
automatiquement. C'est le mode le plus rapide et le moins fatigant.

**Avantages :**

- Geste instantané (moins d'1 seconde par scan)
- Aucune fatigue pour les mains
- Marche sur n'importe quelle page avec un champ de saisie

**Limite :** la douchette doit être branchée au poste depuis lequel
vous travaillez.

## OfeliaScan (téléphone mobile)

OfeliaScan est l'application Android compagnon de BibliOfelia. Vous
scannez avec la caméra de votre téléphone, et le résultat est envoyé à
BibliOfelia.

**Avantages :**

- Pas besoin de douchette ni de poste à côté de chaque étagère
- Idéal pour le récolement (faire l'inventaire dans les rayons)

**Limites :**

- Première utilisation : il faut [appairer le téléphone](../ofeliascan/activer.md)
- Plus lent qu'une douchette (la caméra doit lire le code)

## Le clavier (toujours disponible)

Sur chaque page avec un champ de saisie, vous pouvez taper le code
manuellement et appuyer sur **Entrée** ou cliquer sur le bouton
**Valider** à côté.

**Quand l'utiliser :**

- Pas de douchette branchée
- Le code-barres est abîmé ou mal imprimé
- Vous devez saisir un code que vous avez noté à la main

!!! tip "Conseil"
    Sur les pages **Prêt** et **Retour**, le curseur se place
    automatiquement dans le bon champ après chaque scan ou validation.
    Vous n'avez jamais besoin de cliquer manuellement pour passer au
    livre suivant.

## Recherche par nom au lieu du code-barres

Si vous n'avez ni la carte du membre ni le livre sous la main, utilisez
la **recherche globale** en haut de chaque page : tapez le nom du
membre ou un mot du titre, et BibliOfelia trouve la fiche directement.
